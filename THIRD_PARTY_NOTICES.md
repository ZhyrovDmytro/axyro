# Fancy Components

The letter-swap and animated-underline components in
`src/components/fancy/` are adapted from [Fancy Components](https://github.com/danielpetho/fancy)
by Daniel Petho, revision `f9f62c61207b2dd3210476dd98af3c9a5be24094`:

- `src/fancy/components/text/letter-swap-forward-anim.tsx`
- `src/fancy/components/text/underline-comes-in-goes-out.tsx`

Axyro uses CSS animations instead of Motion, includes keyboard-focus activation,
and disables these effects for reduced-motion preferences.
